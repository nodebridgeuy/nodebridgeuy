# NodeBridge

Somos un equipo de desarrollo de software de Uruguay. Diseñamos y construimos sistemas web a medida, con foco en que sean claros de usar, seguros y fáciles de mantener.

## Quiénes somos

La empresa nació en abril de 2026 en el Polo Educativo Tecnológico Montevideo - Vista Linda, como proyecto de egreso de bachillerato bilingüe. Nos une ser compañeros de clase y compartir los mismos ideales y objetivos. Buscamos crear soluciones a los problemas de las personas mediante el uso de la tecnología, que es nuestra especialidad.

## Qué hacemos

- Desarrollo de aplicaciones web a medida.
- Sistemas de gestión interna para organizaciones.
- Conexión entre sistemas, por ejemplo entre una intranet y un sitio público.
- Ofrecemos un sistema sólido con todo lo que eso conlleva: planes a medida, con un análisis exhaustivo del programa a diseñar.

## Cómo trabajamos

- **Claridad:** interfaces simples, pensadas para quien las usa todos los días.
- **Seguridad:** cuidamos los datos desde el diseño, con permisos por rol y consultas protegidas.
- **Mantenimiento:** código ordenado y documentado, para que otros puedan continuarlo.

## Nuestra ética laboral

1. **Privacidad:** no vendemos ni compartimos los datos personales de los usuarios sin su autorización.
2. **Honestidad:** mostramos nuestros productos y servicios tal cual son, sin ocultar costos ni condiciones y sin información engañosa.
3. **Cumplimiento:** si prometemos un servicio, una fecha o una condición, hacemos todo lo posible por respetarlo.
4. **Responsabilidad:** reconocemos y corregimos nuestros errores, aprendemos de ellos y asumimos toda la responsabilidad.
5. **Respeto:** tratamos a las personas del equipo de manera justa y respetuosa, con decisiones objetivas y las mismas oportunidades para todos.
